# FallGuard - เว็บแอปสำหรับ iPhone

หน้าเว็บของแอปแจ้งเตือนคนล้ม FallGuard เปิดใน Safari แล้ว "เพิ่มไปยังหน้าจอโฮม"

ไฟล์ในนี้มีแต่ตัวหน้าเว็บ ไม่มีกุญแจ ข้อมูล หรือภาพของบ้านใดเลย
กุญแจเข้ารหัสอยู่ในมือถือที่สแกน QR จากโปรแกรม FallGuard บนคอมเท่านั้น
(ลิงก์จับคู่ใส่กุญแจไว้หลังเครื่องหมาย # ซึ่งเบราว์เซอร์ไม่ส่งมาที่เว็บนี้)
